# OpenProbe

An open-source recruitment screening concept focused on observable evidence.

**Status: design stage / pre-MVP. There is no working application yet.**

## Purpose

Give applicants a simple way to demonstrate role familiarity, communication and
judgement when using AI. Give recruiters evidence they can inspect and candidates
feedback they can use.

## Proposed screening layers

| Layer | Activity | Evidence |
| --- | --- | --- |
| 1. Application check | Compare resume claims with the job description | Relevant excerpts, inconsistent claims and questions for review |
| 2. Quick role quiz | Ten timed questions from a role-specific question bank | Initial answers, final answers, response times and session events |
| 3. Workplace simulation | Explain information in chat and organise an AI delegation task board | Communication excerpts, ownership choices, dependencies and review steps |

Selected quiz questions may include disclosed, simulated group suggestions.
Their value as a recruitment signal is an experiment to evaluate.

## First pilot

Start with one data role. Compare AI scoring with independent human reviews and
collect candidate feedback before using the assessment to influence hiring.

Read the [blueprint](docs/blueprint.md) and [roadmap](ROADMAP.md).

## Feedback

Open an issue to discuss the candidate experience, role scenarios or evaluation.
Use synthetic examples. Keep real resumes, candidate records and credentials out
of this public repository.
